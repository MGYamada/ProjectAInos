# Project AInos

*Final answer to Hilbert's sixth problem*

Project AInos is a long-term effort to formalize the whole of theoretical physics in Lean 4. Its approach to Hilbert's sixth problem is to build a library in which the mathematical results of physical theories can be traced back to the assumptions they depend on.

For each theory, the project will define its basic objects, state its axioms, and derive its central results with machine-checked proofs. As the library grows, the project will also formalize the connections between theories, including the conditions under which one theory can be recovered as a special case or a limit of another.

## Project Plan

1. Thermodynamics
2. Mechanics
3. Electrodynamics

The order of subsequent topics is yet to be determined.
